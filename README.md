# Web-Development-Internship

A 45-day Web Development Internship at **ApexPlanet Software Pvt. Ltd.**  
Built with: **HTML · CSS · JavaScript**

---

## Tasks Overview

| Task | Topic | Days | Key Skills |
|------|-------|------|------------|
| [Task 1](./Task-1/) | Basics of Web Development | 1–9 | HTML structure, CSS styling, JS interactivity |

## Task Details

### Task 1 — Basics of Web Development (Days 1–9)
- Created a simple webpage using semantic **HTML** (headings, paragraphs, images, links)
- Styled with **CSS** (colors, fonts, spacing, layout)
- Added **JavaScript** interactivity (button click → dynamic message)

### Task 2 — Intermediate HTML, CSS & JavaScript (Days 10–18)
- Built a **contact form** with multiple input types styled with CSS
- Implemented **JavaScript form validation** (required fields, email format)
- Created a **responsive layout** using Flexbox (nav) + CSS Grid (content) + media queries
- Developed a **dynamic to-do list** with add/remove/filter using DOM manipulation

### Task 3 — Advanced Styling & JavaScript (Days 19–27)
- Applied **responsive design** with media queries (mobile / tablet / desktop)
- Built an **interactive quiz** with score tracking, feedback, and progress bar
- Fetched data from **public APIs** (JokeAPI, Dog CEO API) and displayed it dynamically

### Task 4 — Full Project Implementation (Days 28–36)
- Built a **personal portfolio website** with About, Projects, and Contact sections
- Created a **note-taking app** with `localStorage` for data persistence
- Developed a **product listing page** with search, category filtering, and sort options

### Task 5 — Final Project & Optimization (Days 37–45)
- Built a full **e-commerce web app** (ShopApex) — the capstone project
- Applied **performance optimizations**: lazy loading, reduced HTTP requests, efficient CSS/JS
- Ensured **cross-browser compatibility** and **mobile responsiveness**
- Implemented accessibility (ARIA labels, semantic HTML, `prefers-reduced-motion`)

## How to Run

Each task is a standalone HTML file. Open any file directly in your browser:

```bash
# Clone the repo
git clone https://github.com/SonuKumarDS/Web-Development-Internship.git
cd Web-Development-Internship

# Open any task
open Task-1/index.html
# or drag the file into your browser
```

Works in: Chrome · Firefox · Safari · Edge
